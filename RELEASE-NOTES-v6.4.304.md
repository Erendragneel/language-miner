# Language Miner v6.4.304

The practice progression button now stays labeled **Next**, instead of changing to **Resume** as soon as a question starts. Before the first answer, it remains visible with a short explanation that choosing an answer enables it.

After the first answer is recorded, Next opens another ordinary practice question. This includes incorrect and assisted answers: players can review the correction, optionally retry, or continue without earning duplicate rewards or losing additional hearts. Japanese and the other language courses use the same visible progression behavior.

Smart Review retains its correct-answer requirement. Daily Refresher and timed assessments retain their own progression rules. After reopening the game, Next can start practice or restore an unanswered question when one is retained.

The button and explanation follow the selected interface language. The release also refreshes the installed app cache and complete updater.
