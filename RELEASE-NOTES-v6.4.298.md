# Language Miner 6.4.298

- After account consent and confirming their known and learning languages, new players complete the required, 20-part beginner tutorial before course entry or placement choices. The tutorial replaces the former automatic guide. Placement XP or rewards do not count as game experience.
- Each part explains actual menu labels and asks the player to select a highlighted option in a clearly marked practice preview. The previews never start an assessment, play audio, install the app, spend supplies, change settings, or submit account actions.
- Covers home controls; Explore, Gear, and Player & settings; all Expedition Hub tabs; Course; Writing Practice; Goals; Shop; Inventory; Notebook; Character; Listen & follow along; progress reports; Settings; Account & Support; installation; Parent/Teacher Center; and Help & Community.
- Tutorial position and completed steps use the player's existing device/cloud save. Interrupted tutorials resume after the next manual login. Completion is retryable when both device storage and cloud saving fail.
- Players who already have recorded practice are not interrupted. Everyone can replay the tutorial from Menu → Player & settings → Help & Community; replays can be closed.
- Required mode has no skip or close action. Keyboard focus stays inside its native modal, background controls are blocked, and account consent or course setup takes priority. Narrow phones and reduced motion are supported.
- Tutorial activity is excluded from language-study time, study dates, and streaks. Returning to real practice resumes the existing clocks without crediting deferred tutorial time.
- Tutorial instructions and labels are bundled in all 17 known languages for offline use. These are AI-authored translations; qualified native-language editorial review remains separate.
- The full searchable Game Guide remains an optional reference in Settings. Help & Community also retains guide access and the optional tutorial replay; opening either reference does not reset tutorial completion.
- App-shell, cache, and complete-updater versions are coordinated at 6.4.298.

This website release does not update the separate Android release.
