The extracted path dataset in writing-stroke-data.js is an adaptation licensed under CC BY-SA 3.0. The adaptation selects 188 characters, removes SVG layout and metadata, and stores ordered SVG path strings as JSON. Runtime display scales paths into the practice square without altering their stroke order. Upstream does not endorse this game. Original SVG files remain available at the pinned repository revision.

These models apply to the Japanese course only. Other scripts use whole-shape practice and are not falsely given verified stroke-order grades.
