# Language Miner 6.4.290

Brings the website's wording, pronunciation recordings, and picture corrections up to the Android testing candidate's content while retaining the website's Patreon, Discord, reward animation, wardrobe, and reels.

- Installs the recorded wording corrections and context clarifications. All 1,000 shared vocabulary entries are available across 17 languages; the frozen 5,788-flag queue is resolved. The current shared corpus contains 22,780 localized vocabulary, grammar, and sentence forms.
- Refreshes old review cards from current wording while retaining their IDs, scheduling, and history. Course navigation skips unavailable lessons without awarding completion for them.
- Replaces website pronunciation and story files with the existing paid Azure recordings and adds current-form aliases. Every shared form has female and male recording lookups. No new billable speech generation is performed by this update or by normal recorded playback.
- Adds clearer diagrams, contextual scenes, revised illustrations, and alphabet associations. Known-language context helps explain ambiguous images; Reading and Listening do not expose picture clues before grading.
- Refreshes the media cache identities and recording URLs so older cached audio cannot override the replacement recordings. Pictures and recordings download as needed, with offline reuse afterward.
- Serves pronunciation and stories from the companion `language-miner-audio` GitHub Pages site on the same origin. This keeps both static sites below the publication size limit and preserves the recording bytes and audio quality.
- Preserves the previous assisted-answer, real N5 assessment, Listening feedback, explanation, and save-recovery fixes. The main page, worker, Guardian, and complete updater share version 6.4.290.
- Keeps privacy, terms, notices, and other document links readable when the game is installed or cached, instead of reopening the game for those links.
- Adds the provided public support/privacy contact, `languageminersupport@gmail.com`, to the website's privacy and terms pages.

Recorded correction and file-integrity checks are not qualified native-language certification. Further editorial review remains necessary, and this website publication does not install or upload an Android package or enable Google Play subscriptions.
