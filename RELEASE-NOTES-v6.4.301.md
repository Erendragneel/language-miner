# Language Miner v6.4.301

The beginner tutorial now guides players through the actual game menus on desktop and phones. Kōji gives a short instruction over the game while a gold frame and pointing hand mark the next real control. Menu actions advance the tutorial automatically after the requested screen opens.

New players complete the tutorial after confirming their language pair, before choosing their starting level and beginning normal play. Interrupted progress resumes for the same account. Players who already completed the previous tutorial, and established-player exemptions, remain honored. Replay is available from Help & Community.

The searchable Game Guide remains in Settings and is demonstrated during the walkthrough. Install App is highlighted in Settings without requiring an installation. Navigation does not buy items, claim rewards, change account access or answer questions.

The phone layout keeps the guide panel within the screen and leaves highlighted controls available for tapping. Instructions remain available offline in all 17 interface languages, and Kōji's portrait is included in the web app shell cache.

This release preserves the published v6.4.299 reading-support fixes and Japanese practice controls. The website and installed web app use the same responsive release.

Validation includes the complete 77-action desktop route with saved/cloud resume; the complete 77-action 390×844 touch-emulated phone route; smaller 320-pixel layouts; language-selection handoff for Japanese and Spanish; account isolation; migration/replay; failed completion saves and retry; and release/update identity checks. Browser checks use disposable accounts with mocked cloud responses.
