# Language Miner 6.4.299

- Hiragana and Katakana Expedition Hub mines now include Easy, Hard, Picture, Listening, Writing and Reading, using the same controls and saved selections as the Japanese JLPT and other language courses. Existing lesson locks and course progression stay intact.
- Reading support follows the learning language. Japanese uses kana readings, furigana or the unannotated written form. Korean uses available Hangul letter hints, Mandarin uses available pronunciation controls, and other courses use their existing alphabet information. Course words without reviewed pronunciation text do not receive invented romanization.
- Guided, Standard and Challenge now affect multilingual question presentation. Guided shows available hints, Standard offers optional help, and Challenge reduces assistance. Reading-answer questions and assessments keep answer-revealing hints hidden.
- Easy/Hard no longer silently changes the saved reading-support preference. Changing support refreshes the current question without replacing its answer, recording an attempt or awarding progress.
- Reading-support labels and explanatory text are available in all 17 interface languages.
- Website, offline cache and complete updater use release 6.4.299.

This website release does not update the separate Android release.
